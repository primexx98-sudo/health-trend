# 건강기능식품 트랜드 대시보드 - 사용설명서

**대상:** 비전문가 사용자  
**목표:** 이 문서만 읽으면 누구나 설치하고 사용할 수 있다  

---

## 전체 흐름 한눈에 보기

```
1단계: Python 설치 (처음 한 번만)
    ↓
2단계: 패키지 설치 (처음 한 번만)
    ↓
3단계: 네이버 API 키 발급 (처음 한 번만)
    ↓
4단계: API 키 입력 (처음 한 번만)
    ↓
5단계: 자동실행 등록 (처음 한 번만)
    ↓
6단계: 매일 오전 9시 자동으로 대시보드 열림 ✅
```

---

## 1단계: Python 설치

1. 웹 브라우저에서 **python.org/downloads** 접속
2. "Download Python 3.x.x" 버튼 클릭
3. 다운로드된 파일 실행
4. **반드시** "Add Python to PATH" 체크박스 클릭 후 Install

> 이미 Python이 설치되어 있다면 이 단계 건너뛰기

---

## 2단계: 패키지 설치 (원클릭)

`setup` 폴더 안의 **`setup.bat`** 파일을 더블클릭하면 자동 설치됩니다.

검은 창(명령 프롬프트)이 열리고 설치가 진행됩니다. 완료 메시지가 나오면 창을 닫으세요.

---

## 3단계: 네이버 API 키 발급

### 3-1. 네이버 개발자 센터 접속
1. **developers.naver.com** 접속
2. 오른쪽 상단 로그인 (네이버 계정으로)

### 3-2. 애플리케이션 등록
1. 상단 메뉴 "Application" → "애플리케이션 등록" 클릭
2. 애플리케이션 이름: `건강기능식품트랜드` 입력
3. 사용 API 선택:
   - **검색** 체크
   - **데이터랩(쇼핑인사이트)** 체크
4. 환경: "WEB 설정" → 서비스 URL에 `http://localhost` 입력
5. 등록 완료

### 3-3. API 키 확인
등록 후 나타나는 화면에서:
- **Client ID** (클라이언트 아이디) 복사
- **Client Secret** (클라이언트 시크릿) 복사

이 두 값을 메모장에 붙여두세요.

---

## 4단계: API 키 입력

`src` 폴더 안의 **`config.py`** 파일을 메모장으로 열어서:

```
NAVER_CLIENT_ID = "여기에_Client_ID_붙여넣기"
NAVER_CLIENT_SECRET = "여기에_Client_Secret_붙여넣기"
```

붙여넣고 저장합니다.

---

## 5단계: 자동실행 등록 (원클릭)

`setup` 폴더 안의 **`task_scheduler.xml`** 파일을 이용합니다.

1. 윈도우 검색창에 "작업 스케줄러" 입력 후 실행
2. 오른쪽 패널에서 "작업 가져오기..." 클릭
3. `setup/task_scheduler.xml` 파일 선택
4. 확인 클릭

이제 매일 오전 9시에 자동으로 실행됩니다.

---

## 6단계: 대시보드 사용법

### 자동 실행
- PC가 오전 9시에 켜져 있으면 브라우저가 자동으로 열립니다
- 바탕화면 알림으로 "트랜드 대시보드 준비 완료"가 표시됩니다

### 수동 실행 (언제든 원할 때)
`src` 폴더 안의 **`main.py`** 파일을 더블클릭하면 즉시 실행됩니다.

### 과거 대시보드 보기
`output` 폴더에 날짜별로 저장됩니다.
예: `dashboard_20260628.html` → 더블클릭하면 바로 열림

## 자주 묻는 질문 (FAQ)

**Q. 오전 9시에 자동으로 안 열려요**  
A. PC가 절전 모드였을 가능성이 높습니다. 윈도우 설정 → 전원 및 절전 → 절전 모드를 "사용 안 함"으로 변경하세요.

**Q. 대시보드가 텅 비어 있어요**  
A. 인터넷 연결을 확인하고, `logs` 폴더의 당일 로그 파일을 열어 오류 내용을 확인하세요.

**Q. 네이버 API 오류가 나요**  
A. `config.py`의 API 키가 정확히 입력됐는지 확인하세요. 공백이나 따옴표가 빠지면 오류가 납니다.

**Q. 구글 트랜드 데이터가 가끔 빠져요**  
A. 구글이 자동 수집을 일시 차단하는 경우입니다. 정상적인 현상이며, 나머지 데이터는 정상 표시됩니다.

**Q. 과거 데이터를 비교하고 싶어요**  
A. `output` 폴더에 날짜별 파일이 쌓입니다. 엑셀로 정리하는 기능은 추후 추가 가능합니다.

---

## 문제 발생 시 로그 확인 방법

1. `logs` 폴더 열기
2. 오늘 날짜의 `.log` 파일 더블클릭 (메모장으로 열림)
3. 빨간색 `[ERROR]` 줄을 찾아서 내용 확인
