# 건강기능식품 트랜드 대시보드 - 시스템 설계서

**프로젝트명:** 건강기능식품 트랜드 자동 수집 대시보드  
**최초 작성:** 2026-06-28 | **최종 수정:** 2026-06-29  
**목적:** 사업/마케팅 전략 수립을 위한 매일 아침 트랜드 정보 자동 제공

---

## 1. 프로젝트 개요

건강기능식품 시장의 빠른 변화에 대응하기 위해 매일 오전 9시, 국내외 트랜드 정보를 자동으로 수집·정리하여 GitHub Pages HTML 대시보드로 제공한다.

**핵심 가치**
- 완전 자동화: GitHub Actions 기반, PC 불필요
- 무료: 유료 API 없이 공개 데이터만 활용
- 포괄성: 국내순위·글로벌·SNS·뉴스·연구·규제·해외업계 7개 영역 통합

## 4. 데이터 수집 영역

### 4.1 국내 인기 순위
- **출처**: 네이버 데이터랩 쇼핑인사이트 API (무료)
- **수집**: 건강식품 카테고리 인기 검색어 Top 20

### 4.2 글로벌 트랜드 + 급상승 키워드
- **출처**: Google Trends (pytrends, 비공식 — 간헐적 차단 시 로그 기록 후 스킵)

### 4.3 SNS 화제 키워드
- **출처**: 네이버 블로그/카페 검색 API (무료)

### 4.4 국내 뉴스·연구·규제

**RSS 피드 (주 수집원)**

| 피드명 | URL | trusted |
|--------|-----|---------|
| 연합뉴스 건강 | yna.co.kr/rss/health.xml | True |
| 헬스조선 | health.chosun.com RSS | True |
| 식품음료신문 | thinkfood.co.kr RSS | True |
| 팜뉴스 | pharmnews.com RSS | False |
| 메디소비자뉴스 | medisobizanews.com RSS | False |
| 식품저널 foodnews | foodnews.co.kr RSS | False |
| 뉴스1 생활 | news1.kr/rss/life.xml | False |

> `trusted=True` 피드도 HEALTH_KEYWORDS 1개 이상 매칭 필수 (병원뉴스 차단)

**네이버 뉴스 검색 API** — 보조 수집 (NAVER_CLIENT_ID / NAVER_CLIENT_SECRET 시크릿)

**키워드 설계**

| 구분 | 역할 | 예시 |
|------|------|------|
| HEALTH_KEYWORDS | 수집 필터 | 건강기능식품, 영양제, 비타민, 유산균, 개별인정, 고시형, 기능성 등 |
| EXCLUDE_KEYWORDS | 병원뉴스·무관주제 차단 | 수술, 입원, 병원, 건강보험, 급식, 외식 등 |
| RESEARCH_KEYWORDS | 연구 카테고리 분류 | 연구, 임상, 논문, 학회, 메타분석 등 |
| REGULATORY_KEYWORDS | 규제 카테고리 분류 | 식약처, 개정고시, 개별인정형, GMP, 허위광고, 리콜 등 |

### 4.5 해외 업계 동향
- **출처**: ScienceDaily (dietary supplements / nutrition / vitamins), Nutraceuticals World
- **번역**: `deep-translator` 라이브러리 (무료, API 키 불필요)
- **한도**: 월 49만자 — 초과 시 영문 원문 표시
- **사용량 추적**: `트랜드/data/translate_usage.json` (매 실행 시 커밋)

## 6. 워크플로 (GitHub Actions)

| 파일 | 스케줄 | 역할 |
|------|--------|------|
| `daily.yml` | 매일 00:00 UTC (09:00 KST) | 수집 → 대시보드 생성 → GitHub Pages 배포 |
| `keepalive.yml` | 매주 월요일 | daily.yml 재활성화 (GitHub 스케줄러 중단 방지) |

**pip install (daily.yml 하드코딩)**
```
pip install requests pytrends beautifulsoup4 lxml deep-translator
```

## 8. 제약사항 및 유의점

- Google Trends: 비공식 API, GitHub Actions IP에서 429 차단 발생 → 로그 기록 후 스킵
- 네이버 API: 일일 호출 한도 존재 (설계 범위 내 충분)
- deep-translator: 비공식 Google 연동, 간헐적 차단 가능 → 실패 시 영문 원문 표시
- 수집 결과 품질은 키워드 설정에 의존 — `news_collector.py` 상단 키워드 직접 수정 가능
