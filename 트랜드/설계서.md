# 건강기능식품 트랜드 대시보드 - 시스템 설계서

**프로젝트명:** 건강기능식품 트랜드 자동 수집 대시보드  
**작성일:** 2026-06-28  
**목적:** 사업/마케팅 전략 수립을 위한 매일 아침 트랜드 정보 자동 제공  

---

## 1. 프로젝트 개요

### 1.1 배경 및 목적
건강기능식품 시장의 빠른 변화에 대응하기 위해 매일 오전 9시, 국내외 트랜드 정보를 자동으로 수집·정리하여 HTML 대시보드 형태로 제공한다. 사용자는 별도의 기술 지식 없이 자동으로 열리는 웹페이지를 통해 당일 트랜드를 확인할 수 있다.

### 1.2 핵심 가치
- **자동화**: 매일 오전 9시 PC 켜져 있으면 자동 실행
- **무료**: 유료 API 없이 공개 데이터만 활용
- **직관성**: 클릭 없이 브라우저에서 바로 확인
- **포괄성**: 국내 + 글로벌 + SNS + 뉴스/연구 4개 영역 통합

## 3. 데이터 수집 영역

### 3.1 국내 인기 성분/제품 순위
| 항목 | 내용 |
|------|------|
| 데이터 출처 | 네이버 데이터랩 쇼핑인사이트 API |
| API 유형 | 무료 (일 1,000회 제한) |
| 수집 항목 | 건강식품 카테고리별 인기 검색어 Top 20 |
| 업데이트 | 전일 데이터 기준 |

### 3.2 글로벌 트랜드
| 항목 | 내용 |
|------|------|
| 데이터 출처 | Google Trends (pytrends 라이브러리) |
| API 유형 | 무료 (비공식 라이브러리) |
| 수집 항목 | 글로벌 건강보조제 검색 트랜드, 급상승 키워드 |
| 업데이트 | 실시간 기준 |

### 3.3 SNS 화제 키워드
| 항목 | 내용 |
|------|------|
| 데이터 출처 | 네이버 블로그 검색 API, 네이버 카페 검색 API |
| API 유형 | 무료 (일 25,000회 제한) |
| 수집 항목 | 최근 24시간 내 화제 키워드, 언급 빈도 |
| 업데이트 | 당일 기준 |

### 3.4 뉴스/연구 동향
| 항목 | 내용 |
|------|------|
| 데이터 출처 | 네이버 뉴스 API, 식품의약품안전처 RSS |
| API 유형 | 무료 |
| 수집 항목 | 건강기능식품 관련 최신 뉴스 Top 10, 정책/연구 동향 |
| 업데이트 | 당일 기준 |

## 6. 기술 스택

| 구분 | 도구 | 이유 |
|------|------|------|
| 언어 | Python 3.11+ | 무료, 라이브러리 풍부 |
| 트랜드 수집 | pytrends | Google Trends 무료 연동 |
| 뉴스 수집 | requests + BeautifulSoup | 가볍고 무료 |
| 차트 | Chart.js (CDN) | HTML에 내장, 설치 불필요 |
| 자동실행 | Windows 작업 스케줄러 | OS 내장, 별도 설치 불필요 |
| 대시보드 | HTML + CSS (Bootstrap) | 브라우저만 있으면 OK |

## 9. 제약사항 및 유의점

- Google Trends는 비공식 API로 간헐적 차단 가능 (재시도 로직 포함)
- 네이버 API는 일일 호출 한도 존재 (설계 범위 내 충분)
- PC가 오전 9시에 켜져 있어야 자동 실행됨 (절전 모드 해제 권장)
- 인터넷 연결 필수
